# v0.6.1：主时钟显示优化

本版基于 v0.6.0，只修改主时钟的呈现方式。NTP 采样、估计器、冻结边界、内部 QPC 时钟和输入执行线程保持原实现。

## 显示方式

- 秒数：深青色、粗体、大字号，作为主视觉重点。
- 时分：灰蓝色、常规字重，字号低于秒数。
- 毫秒：小号灰色，继续保留三位数字，约每 **100 ms** 更新一次。
- 三段使用等宽数字、固定位置和同一基线。普通/精简模式按相同规则缩放。

100 ms 只是显示采样间隔；每次显示的三段均来自同一次实际时钟采样，不把内部时间取整至 100 ms。GUI 原有轻量定时消息继续检查秒边界，因此在界面线程正常运行时，换秒不会额外等待完整的显示间隔。Windows 忙碌时 GUI 仍可能延迟，但不改变独立执行线程的截止时刻。

## 闪烁修复

旧版约每 33 ms 给普通 STATIC 控件写入完整时间，并通过 `InvalidateRect(..., TRUE)` 请求擦除背景，存在先出现背景、再出现文字的重绘过程。

新版使用独立时钟控件：在复用的内存位图中完成不透明背景和三段文字绘制，再一次性复制到屏幕。控件不单独擦除背景；毫秒变化时只使其自身区域失效，时分秒变化时更新对应区域。缩放和切换窗口模式时完整重绘缓冲，避免旧字号和旧布局残留。

## 验证

- 最终 Windows x64 构建：143 项检查全部通过。
- GDI 像素检查：同一 100 ms 显示区间不触发重绘；毫秒变化仅使右侧区域失效，时分秒像素保持不变。
- 向控件发送背景擦除消息，既有帧的像素没有被清空。
- 跨秒、时间回拨和辅助功能文字保持完整采样时间。
- 普通/精简布局，96/120/144/192 DPI，累计 1,600 帧：文字保持可见，没有上下/右侧裁切，连续绘制未观察到 GDI 句柄增长。
- 使用隔离配置实际检查普通/精简模式切换、主时钟字体、颜色和布局；用户预约与系统时间不受测试影响。
- 最终 EXE 的 GUI 自测通过：本窗口收到一次 F8 按下和释放，观测保持约 19.78 ms，自动准备提示、恢复同步、下一小时预约和重启恢复均通过。

像素检查用于验证控件绘制逻辑，不等同于对所有显示驱动和远程桌面环境进行长时间录像验收。日常试用若仍有异常，应区分数字正常变化、窗口遮挡恢复和整片时钟短暂空白。

## 使用

运行 `Ctimer-v0.6.1.exe`；或关闭旧程序后用新版替换 `Ctimer.exe`，保留原有 `Ctimer.ini`。无需迁移配置，也无需重新设置预约。
